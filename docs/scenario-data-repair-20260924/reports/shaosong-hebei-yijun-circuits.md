# 绍宋·河北义军补路一级报告

河北义军行政树去掉「两河忠义寨」顶节点，4 块分到 1 路下。全国合计守恒自检：口、户、丁、逃户、隐户、应征、实征、起运、留用、库钱、库粮、库帛、商贸、驿站、解额、地块数 全部与改前相等。

户数：磁、相二州取《宋史·地理志》崇宁户；赞皇县按赵州县等切出；五马山寨志无户数，估两千户。
