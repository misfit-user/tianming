# 晚唐·外藩各道描述报告

同一势力内改挂 4 块；重写 31 道（日本 8、吐蕃 5、回鹘 4、黑水靺鞨诸部 2、室韦诸部 2、吕宋诸部 2、下缅甸河谷诸聚落 2、环王 2、湄公河上游诸部 2、南诏 2）。只写范围与所辖地块、治理结构和开局时（开成五年正月十四日）的实情，每句事实附原文；可信度 L 的是史料稀少、据铭文或考古的二手研究。
