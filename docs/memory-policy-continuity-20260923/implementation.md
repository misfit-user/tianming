# 政策连续性与压缩改造实施记录

本次在当前本地运行树的隔离副本实施，未打包、推送或发布。真实玩家存档和接口配置未用于测试。

## 已落地的行为

- 现行政策沿用 activeEdicts，分开法令效力与执行进度，带稳定 ID、版本、完整条款、范围、条件、例外、期限、账户/周期说明和修订回执。颁行任务办结不使政策失效；明确暂停、撤销、到期或替代才退出有效规则。
- 主推演通过 policy_updates 登记变化。普通 Agent、问天/天意与回合复核共用 update_policy；广泛世界编辑仍可使用，实际改动会补记政策版本。此入口不扣钱：具体支付继续走原财政账，避免记忆回放产生重复支出。
- 兼容皇命表数组行，保留隐藏权限、稳定引用和撤销覆盖。有效政策优先于长人物名单；完整条款不再被通用条目字数截断。窗口放不下时提供未展开计数/索引，不假装全部读到。
- 真正发出请求前，记录政策 ID、当前版本和全文覆盖的元数据，不记录请求正文、Key 或接口配置。记忆面板可查看最近请求的覆盖情况。
- 默认 AI 记忆进入归档投影；未声明公开的 AI 工作记忆仅供世界推演读取，不能成为 NPC 全知信息。原文检索可以命中索引预览之外的尾部条款。
- 普通压缩、记忆管家、L2/L3 与 Agent 整理均保留原始来源，并核对输入、世界、回合、读档代数和政策版本。晚回包丢弃；并发追加保留。整理失败、容量不足或预算不足保留原文，不回滚已完成的主推演。
- 长记录按条款/重叠段切分，精确原始对象先存档。摘要遗漏的数字、否定、例外等保留为独立原文片段；主题与阶段由现有压缩调用整理，未新增固定付费调用。
- 原文采用随 canonical 存档携带的 JSON 字符串块及轻量索引。读取时只展开选中块，保存快照不反复解析所有原文。容量达到 1200 万字符后停止破坏性替换，保留活跃源；未升级 IndexedDB 版本，也未改变配置存储。
- 旧档分批归档，继承实际保存分叉之前的来源；不根据旧史关键词擅自恢复政策。未完成事项不再仅因超过 30 回合或新线索增多而被抛弃。
- Ctrl+M 的记忆面板新增“政策与长期记忆”，可查看政策效力、执行状态、原文与修订历史，修正、置顶、暂停/恢复，并分页读取历史原文。

## 验证及边界

已通过 11 项原始漏点回归，以及 23 组生命周期/压缩/隐私回归。其中包括 100 个连续回合的合成状态推进、三次保存分叉、重复压缩、并发追加、源修改、切世界、晚回包、容量不足、政策替代与撤销、真实快照函数序列化及输出请求覆盖。

独立 Electron 客户端载入完整页面，使用专用临时用户目录。通过实际 TM_SaveDB 保存，退出进程后重开，读回政策与压缩前原文；记忆面板已实际渲染并截图检查。此测试没有使用玩家档。

全量 1093 项烟测通过；最终记忆、Agent、问天、复核与上下文相关 145 项复跑通过，另有日常目录 34 组专项回归、13 项架构守卫、41 条官方剧本对账、182 条跨管线契约及 1328 项基线对齐全部通过。42 个文件已对账写回日常目录，最终字节与隔离副本一致。详细证据见 verification.json。第一轮 1093 项测试发现并修复了新功能登记/格式接线；旧恢复测试按实际异步顺序等待；共享 node_modules 的 npm 闭包误报用独立副本消除，未修改日常依赖；旧地图标签拆层对缺失节点补了防御，不改变有效地图行为。

没有进行真实付费模型的百回合对照。确定性测试证明源保留、有效政策供给与保存恢复，不能保证模型永不误解。超大政策集合仍受实际上下文预算约束；原文档案随存档携带，尚未改成独立按页数据库，以避免存档移植、事务和旧客户端兼容风险。
