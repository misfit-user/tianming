# 舆图深度缩放：128倍与小地块定位

## 当前状态与使用

修改已写入本地项目的原生舆图代码，不是浏览器临时注入或独立审图器。
重新启动本地源码版游戏后生效；无需重新导入剧本。已打包安装包和线上版本未发布更新。
滚轮、地图加减按钮和触屏双指统一使用0.72至128倍。原滚轮/双指上限3.4倍，原按钮上限4.2倍。
滚轮围绕指针缩放，按钮围绕视口中心缩放，双指围绕两指中心缩放；不会混用输入后突然退回旧上限。
检索并定位小地块会按其实际尺寸放大，最大128倍；不挪动地块或伪造地形。
使用复位或原有全图操作可返回总览。府州/省道/天下与已有层级锁定规则保持。

## 渲染与范围

低倍率继续复用三层预加载图面；超过4.2倍使用裁切于视口内的SVG矢量变换，避免将整幅屏幕纹理放大128倍。
修正SVG以填充范围作为坐标原点造成的高倍率偏移；边界使用不随比例增粗的描边。
高倍率的大片区标签限制屏上尺寸，标签碰撞网格对极大包围盒设置有界单元尺寸。
本改动不能增加原地图本来没有的历史精度，也不是无限制放大。
