# 晚唐·人物字段去伪报告

晚唐 434 名人物里，多数字段是把生平、性格、志向、辞令、内心独白原样抄进去凑出来的，另有制作时的自我说明直接写在图志字段里。本补丁删去抄件与制作用语，把 personalGoals 改为引擎要的对象。数字、生平正文一概不动。

## 样例

- birthplace 只留地名：
  - 出生地：东宫（本纪明确记出生于此） → 东宫
  - 出生地：大明宫（本纪明确记出生于此） → 大明宫
  - 籍贯：邯郸（本传籍贯）；此处不等于已证出生地 → 邯郸
- appearance 去说明：
  - 史传记“狀纖頎，頗類帝”；具体五官与肤色未详。 → 史传记其“狀纖頎，頗類帝”。
  - 《旧唐书》形容：“形狀眇小而精悍。”服饰、肤色与面部细节未详。 → 《旧唐书》记其“形狀眇小而精悍”。
  - 《池上篇》自写“白須颯然”，是文学自述，不等于可精确复原肖像。 → 《池上篇》自写“白須颯然”。
- officeEvidenceNote 删去：
  - 崔珙：盐铁使职起任日待考；沿用现版，不增度支权或宰相权。
  - 李绅：检校兵部／吏部尚书存在时点差异；暂不新增唯一加衔。
  - 李石：外镇使相，不占长安宰相席。
- mentor 去说明：
  - 令狐楚（本传记资助、延入幕府；不是无据认定的正式师承仪式） → 令狐楚
- learning 生平段落清空：
  - 嗢没斯：去年牙帐易主，拥兵者换了效忠的方向，牧户却连失了牲畜。嗢没斯
  - 阖馺可汗：彰信可汗死后，诸贵人推立阖馺。新坐上的汗位，四周仍是扶立他的
  - 太和公主：太和远嫁漠北已近二十年。长安的亲人隔着沙碛与关塞，牙帐的可汗
- learning 去说明：
  - 方术、道教活动（具体师承未核） → 方术、道教活动
  - 以鞫疑狱见用；科第未详 → 以鞫疑狱见用
