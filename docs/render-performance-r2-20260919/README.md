## 实际修复
### 正式地图：消除无变化 DOM 更新
文件：web/phase8-formal-map.js。
原先 updateMapChrome 写入简短提示，renderMapAlerts 随后写入完整提示，同次刷新反复改写；警示按钮也每次重建。
现在统一提示内容，文字、属性、按钮和图例仅在变化时更新；缓存浏览器规范化后的 HTML，仍检查实际 DOM，外部修改后可以修复，避免永久沿用失效内容。深度缩放的 SVG transform 也只在变化时写入。
地块易主、改名、告警、视图切换仍读取当前数据，没有把运行时状态永久缓存。

### 几何缓存：去掉命中时的长字符串重复构造
文件：web/tm-map-realm-layout.js。
不可变字符串路径使用私有 WeakMap 快速识别缓存命中；不再为相同的长路径反复构造带前缀的签名。坐标数组和可变的自定义字符串对象仍完整校验，清空缓存同时清空路径记录。没有改原始地块坐标或几何解析算法。

### 人物志：停止隐藏面板的排队渲染
文件：web/tm-renwu-ui.js。
分批生成卡片时重新检查面板可见性与容器连接状态；关闭/移除面板后停止后续批次，隐藏期间的刷新使旧任务失效。重开时完整重建，保留显式 force 渲染。
受控 1000 人测试：显示首批 80 张后关闭，旧版继续生成剩余 920 张；新版停止在 80 张，重新打开仍完整显示 1000 张。

### 战斗：缓存着色器参数位置
文件：web/battle/index.html，仅 R3D 闭包。
按 WebGL 上下文、着色器程序、参数名缓存位置，包含 null / -1；不同程序和上下文不共享句柄。保留每次真正的参数上传、绘制和纹理更新。
实际函数的模拟 GL 测试：60 次网格绑定的属性查询 180→3；60 次单位绘制的位置查询 120→2，绘制和上传次数不变。
