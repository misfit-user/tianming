# 战场最终优化与网页发布验收

## 范围

本轮在 `codex/fix-personal-campaign-trigger` 完成兵模、将领识别、地形表现和性能收尾，并准备合并本分支已验收的亲征/启动恢复/两阶段地图成果。仅发布网页版；不改版本号，不发桌面/安卓 OTA 或安装包，不触碰玩家存档、API 或暂停的晚唐/原生开局工作树。

## 实现

- `web/battle/unit-assets.js`：可编辑原创程序模型。长枪、刀盾、镋钯、突骑、铁骑、弓骑、弓、弩、火铳、火炮、御营与具名将领；独立武器轮廓、马铠、甲片、披风。四档细节（第4档只用于投影高度小于18像素）、部位动画、材质分色；保留原 GLB 兼容回退。
- `unit-render.js`：实例化、距离/画质细节、逐组复用 CPU/GPU 上传缓冲，具名将领优先可见；炮车进入真实 3D 层。仅改变表现，不削减真实兵额或战果。
- `unit-command.js` 与正式适配器：稳定 ID 优先、同名歧义不随意选人；兼容顶层及 `abilities/stats/attributes/capabilities` 数值，保留 0，过滤非法数并披露默认值。不将任意描述文本当可执行技能。
- 匿名裨将不再成为伪英雄；单阵、首队留在预备队及增援的真实主将能够出场，同一人物不重复出现。已有战法按当前武勇/军事/智谋和兵种派生；能力变化后重新计算。镇抚可以收拢符合条件的溃军，失能将领不再施放战法或提供光环。
- 将领命运按人物 ID、母军、阵营匹配，避免同名敌我串写；重伤、被俘、阵斩、溃逃映射到正式军事写口。待入场预备队完整保留，入场后沿稳定源 ID 统计伤亡。
- 预测器原先检查不存在的 `MilitarySystems.calculateArmyStrength`，从而落入备用公式；现在优先正式全局战力函数。该函数也按稳定主将身份读取能力。
- 静态地物姿态与视图批次缓存；镜头不变时无需重复上传地物实例。阵列槽位复用，通行热路径去除重复坐标数组分配。四向布阵显示与真实通行边界对齐；嵌入战场开场提示不再串用原型历史名册。

## 性能说明

同一 22,000 实际兵额样本、相同地图/视角/均衡档：原兵模实例三角形 **5,748,996**，新兵模 **1,185,206**，减少约 **79.4%**；新实现可见实例 **1755**，没有用减少真实兵额获得降幅。此为兵模几何负载，不等于整帧加速 79.4%。

该机该窗口原生帧间隔中位数 **35.1ms**、P95 **53.1ms**。短时 8 次同步 draw 测量仍包含 **65.2ms** 长帧，不据此声称消除所有卡顿。镜头静止重复绘制时，地物实例上传 **0 字节**、兵模与地物 GPU 缓冲分配数均不增长。

## 边界

这是程序化美术与现有渲染器完善，不是《全面战争：三国》的完整美术重制；未使用 Blender、扫描材质或付费生模服务。人物文本特质不被擅自翻译成新技能；战法仍属现有规则的数值/兵种派生。未新增建筑破坏、完整弹道遮挡或逐兵动态投影，也不宣称全平台长时压力认证。

## 远端失败后的性能修订

PR #81 首次远端 run `34761597353` 的 guards/mobile 通过，但 Windows 战术地图帧间隔 median **765.7ms** / P95 **843.7ms** 失败。没有合并、豁免或调高原 **80/160ms** 阈值。

追加：全分辨率静景色深缓存（仅无MSAA上下文）、原生深度遮挡/复用/失效/尺寸改变像素测试、精确顶点索引、逐实例而非逐顶点计算动画三角函数、18像素以下远景模型、离屏画布上传与光晕/小地图缓存。硬件多重采样路径不走单样本静景缓存，保留边缘质量。河流/海岸粗筛仍回到原精确判定，**48,858** 个陆地、水边与桥渡样本逐项结果相同。

软件诊断明确区分 [Chromium 官方文档中的两种 SwiftShader 用法](https://chromium.googlesource.com/chromium/src.git/+/refs/heads/main/docs/gpu/swiftshader.md)：`--software-gpu` 强制全ES驱动（连浏览器合成都软件化）；`--software-webgl` 在锁定 Electron 33 中用 `--disable-gpu` 观察现有自动 WebGL 回退。均是隔离测试进程参数，未加 unsafe/no-sandbox，也不修改玩家设置。全ES原始本机633.3/1049.9ms，修订后仍约116–150ms中位数；普通回退本机125% DPI最终83.3/100ms（`ed2c1eae-dc47-496b-b7a3-c97e9ade48b3`），**仍超过80ms，不算通过**。这些不同环境的数据不混为同一A/B加速比。

WebGL2/native-blit、统一HUD、desynchronized实验没有验证出收益，已撤销；失败证据保留。帧缓存的真实原生像素对照、前后遮挡及失效检查随原六地图流程运行：`37510dfb-5452-42f7-a891-1c8f6cad7c6c` **30项通过**。后续正式门禁与上线另按最新回执记录；不宣称纯CPU、高DPI或所有设备均达到稳定60帧。
