# 天命美术宪法（v1 · 2026-09-25 定稿）

> 一句话：**常驻的用漆，读写的用纸，全屏场景用画，地图随纸。印刷的用宋，手写的用楷，题额用书法。**
> 颜色和字号只从一张令牌表里取，谁也不许再抄一份调色板。

依据：2026-09-25 对 1.3.5.2（main 52ec91a2）叠全套素材实跑一局天启的逐屏截图，加运行时代码计数。
执行守卫：`scripts/lint-design-tokens.js`（见 [arch-guards.md](arch-guards.md) ⑨）。

## 为什么要立这一页

- 切到「青绿」主题加「特大」字号并保存后，右栏、诏付有司、顶栏四个徽章的像素变化为 0%，顶栏左段 0.3%。设置里的主题和字号对御案主界面基本无效。
- 主界面一屏可见文字用到 6 种字体，楷体占 51%，设置里选的正文字体只管到 40%。
- 运行时写死的颜色 12564 处、写死的字号 5511 处（第0刀基线）；金色一族有 759 种不同写法，绢本调色板在 4 个文件里抄了 5 份。
- styles.css 顶上本来就有三层令牌（v2）。御案界面没用它：主样式表写死颜色两千多处，引用令牌一百来处。所以宪法不另起炉灶，是让御案回到 v2，并补上 v2 缺的「漆」「纸」两族。

## 材质：按功能分，不按冲刺分

一个界面用哪种材质，只看它是「常驻、随手查看」还是「打开来专门读写」。御案时政（深色外框里摆一叠纸笺）是现成的样板。

- **漆（常驻、随手查看）**：顶栏、右栏图标与抽屉、书案、邸报速览、底栏三件、地图工具、暂停菜单。
- **纸（打开来专门读写）**：
  - 绢本：只给诏书，带木轴。
  - 纸笺：奏疏、鸿雁、邸报全文、剧本详情、时政纸条。
  - 书册：史册、人物图志、方志、通志、设置典章。
- **画（全屏场景）**：菜单页、朝议场景卡、过场图、开局叙事页。图里不画字，字一律用真字叠上去（生图写不出汉字）。
- **图（地图）**：色温跟纸走，暖、淡设色；势力色只作区分，不抢画面。

## 字体：印刷用宋，手写用楷，题额用书法

- **题额**（24px 以上的大标题）：马善政。
- **印刷**（正文、标签、列表、账本、邸报）：思源宋体。宋体成形于明代刻书，也是小字号下最清楚的中文衬线体。
- **手写**（御批、朱批、书信和诏书的正文）：楷体。
- **数字**：一律等宽数字（`font-variant-numeric: tabular-nums`）。
- 随包字体要子集化，保留三部剧本人名、地名里的生僻字，缺字回落系统宋体。楷体在安卓上没有，要么随包带一套，要么接受回落。

## 字号：一套刻度，一个开关

- 刻度（以 1920 宽舞台计）：12 / 13 / 14 / 16 / 18 / 22 / 28 / 36 px。全局不许小于 12px，阅读正文不小于 14px。
- 手机按舞台缩放后，正文不小于 12 个 CSS 像素。
- 令牌用 rem，设置改根字号，所有字号一起缩放。
- 设置里「界面字号」「全局字号」「分区字号」合成一个开关，分区微调收进「高级」。

## 图标

- 以右栏九枚的扁平设色风格为基准：同一笔触粗细、同一视角，设色从令牌表的金、朱、青、靛、紫里取。
- 先修两枚容易认错的：虎符（现在像两块鞋底）、纲纪罗盘（现在像一只眼睛）。
- 顶栏资源的黑色象形、史册库的彩色单字方块、面板里的 emoji，逐步改画成同一风格。菜单页的单字印属于场景画，不动。
- 不再新增 emoji。

## 地图与立绘

- 地图色调另出样稿（先试给 B5 加暖色调色），看过再定。另两处顺手改：天下级贴图的矩形硬边羽化进边框；舆图工具里的底图诊断信息收进调试模式。
- 立绘维持现状。

## 怎么守住

- **一张令牌表**：以 styles.css 的 v2 三层令牌为唯一来源；主题只改令牌，不改组件。
- **一道守卫**：`lint-design-tokens.js` 按文件统计写死的颜色和字号，基线只许降不许升；新文件从 0 起算。确经裁定的例外（如图标插画设色）在该行标 `design-ok`。
- **每刀两道验收**：默认主题下逐屏像素差接近 0；切主题、调字号后，主界面确实跟着变。
- **复用不复制**：新面板要用绢本、书册、纸笺，引用同一份材质，不许再抄一份调色板。

## 落地顺序

0. 定稿本页；按现值把色板加进令牌表；立守卫并记下基线。画面不变。（2026-09-25）
1. 御案主界面的颜色收进令牌（顶栏、右栏、书案、底栏）。默认主题像素差接近 0，切主题开始真正生效。
2. 字号收进令牌；设置里三个字号开关合一；落实最小字号。
3. 正文换思源宋体、题额换马善政，并做子集化；楷体只留给手写的内容。
4. 材质归位：邸报全文、剧本详情改纸笺；绢本调色板五份合一；奏疏、鸿雁、史册补上纸的质感。
5. 图标在现有风格里完善：先修虎符和纲纪罗盘，再把顶栏、史册库和面板 emoji 收编进来。
6. 地图：出 B5 暖色调色样稿，看过再定；矩形硬边羽化，诊断信息收进调试。
