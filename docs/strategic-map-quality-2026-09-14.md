# 正式大地图：疆域国名、舆图质感与交互性能

本轮基于已部署的 `4b5fc853`，工作分支 `codex/strategic-map-quality-20260914`。战场已完成 PR #81 与网页版部署；这里的大地图改动仍是本地候选，不代表公开网页已经更新。没有改动剧本原始地理数据、存档、API 设置，也没有发布桌面／安卓 OTA。

## 实现

- 国名字号来自实际疆域面积、可容纳文字的形状与名称长度；联合省份后选择横排／竖排／适度斜排，不再按名字随机倾斜或强制最大国家使用固定大号字。
- 区分岛屿、飞地与孔洞；优先主要连通领土，边界内留白。空间不足时只使用剧本已有简称，不杜撰国号。不可读的小国改为可见标记，完整名称与势力档案仍可访问。
- 读取真实字体包围盒，居中并约束在拟合范围；字体加载后重测一次。国名、地名、疆域原地更新会使相关缓存失效，不会因“顶点数量没变”继续显示旧结果。
- 细纤维纸纹、青绿海面与按区域声明地形绘制的山／丘／林／草／荒漠符号。符号是舆图图例，不是伪造的真实海拔／河流数据。财赋等数据视图降低纹理存在感，保留原始数据着色。
- 平移复用保留的地图图层，避免逐帧重画全部区域路径；拖动不生成省份提示。修正宽高比例变化后的轮缩／触屏坐标，保留缩放、点选与窗口变化的一致投影。
- 标签碰撞使用实际显示比例与字体宽度；隐藏层不抢键盘焦点。原生鼠标捕获不再把国名点击误当作省份点击，Enter 也可打开对应势力。
