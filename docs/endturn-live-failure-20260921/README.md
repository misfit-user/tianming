## 根因和修复

1. 完整主账本尾随游戏既有的 tableEdit 记忆块，被新恢复校验当作非法 JSON。正常账本被拒绝后触发字段过简的救援，最终因缺财政 target/kind 而整回合回滚。现在只接受完整 JSON 加完整、语法有效的既有表格通道，原始字节继续交给记忆消费者；多份顶层 JSON、残缺结构和不支持的命令仍拒绝。
2. 预检把 regionMap 与 adminHierarchy 中同 ID、同名的地区镜像算成重名，并与任命执行器的地方职种规则不一致。已统一；不同 ID 的同名地区、未知官职和非法实体仍拒绝。
3. 央地财政优先采用硬编码旧省 ID，而且结构化动作没有传递来源账户。现在优先真实地区 ID，传递 fromAccount；调拨单承担唯一扣款，真实回执进入财政校验，避免补扣。已用真实财政与政务模块验证内帑单次扣款、国库不动和资金不足回滚。
4. 叙事关键词把“边备倾颓”“钞关”及既有灾情、民变当成必有新增对象。四类低置信度告警保留给一致性复核；实际写入失败、数额不一致、身份冲突、明确未落地婚姻/外交/新法仍阻断。诏令校验另识别本回合正式 _edictTracker，避免要求生成影子 activeEdicts。
5. 输出校验与提示的 shizhengji_basis/resource_changes 类型矛盾已修正，并保留旧格式兼容；主推演与救援共用明确的账库、金额和官职字段说明。
