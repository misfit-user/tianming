## 后台 Agent

初核仍在主推演之后与其他生成并行。主回合不等待它完成；主存档提交后，它独立核对完整原文、实际数据与失败项目，通过正式工具补正，再读取真实变化进行核验。补正和核验状态另行保存。

每条纪事的 `agentReview` 留下状态、逐笔改动、实际差异和来源覆盖情况；未完成时还保留原文证据，后续复核可通过待复核目录读取。未核完就是 pending，不标成 verified，也不撤销已提交主回合。叙事修订同步到纪事字段，并以转义后的修订内容补入阅读页。

开始下一回合时停止旧复核写入；读档、世界引用、战役或时间线变化也会使旧回包失效。已原子回滚的主批次可由后台 Agent 修正后重放；不能盲目重跑已成功批次。
