## 每块依据

- 应天府：南京城是明末东南最大的消费与出版中心；守备太监、六部冗官多，吏治偏浊；京营与操江驻军，军压偏高。
- 苏州府：苏州一府税粮占南直隶近四成（洪武秋粮 274 万石）；逋赋积年；天启六年开读之变，民情激愤；织造太监李实在此。
- 松江府：洪武税粮 122 万石，与苏州并称重赋；棉纺织业最盛；沿海有两浙下沙盐场。
- 常州府：东林党人根据地（东林书院天启五年毁，高攀龙天启六年殉节）；洪武税粮 65 万石。
- 镇江府：江南运河入江处，漕运枢纽；镇江卫驻军。
- 扬州府：两淮三十盐场，泰州、通州两分司共二十场在扬州府境（约三分之二）；盐政积弊，吏治偏浊。
- 淮安府：淮安分司十场；黄淮交汇，水患频繁；漕运积弊。
- 凤阳府：中都与皇陵役重；淮北水旱频仍，流民多出于此（崇祯八年即有农民军焚皇陵之事，此时已见端倪）。
- 安庆府：洪武时土著仅占两成余，余为江西、徽州移民（曹树基）；人均田地为南直隶最少之列。
- 徽州府：人均田地仅四五亩（徐国利 2020）；徽商财富汇回本籍，宗族势大。
- 宁国府：泾县宣纸；洪武田土 775 万亩而人口 53 万，山地多，折实田远少于册面。
- 太平府：芜湖抽分厂（竹木税）；巢湖、无为一带圩田。
- 池州府：南直隶户口最少的府之一；九华山。
- 徐州：直隶州，长官知州；天启四年黄河决口，州治迁云龙山（《明史·地理志》卷40）。
