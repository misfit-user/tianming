# 国师响应恢复与放行模式修复

本批基于本地 `c08478b5`（上一批玩家反馈修复）继续开发，分支 `codex/fix-guoshi-response-autoapply`。仅本地修复和隔离回归；未推送、合并、部署，未修改玩家存档、API 配置或第三方服务器。

## 已确认的问题与改动

1. **响应格式异常后直接失败**：原 provider 对所有 `authoring-response-*` 立即终止，没有完整响应恢复。现在对无效 JSON、事件流未完整结束自动重取本轮响应一次。请求内容、原生工具、思考历史和输出预算均保留，不通过裁剪内容或放宽工具校验提高成功率。
2. **中转事件组装兼容性**：保留标准多行 `data:` 拼接；另支持每行都为完整事件、但遗漏事件间空行的返回。完整 `message` 快照与 `delta` 混用时，校验内容及工具身份一致后使用快照，不重复拼接函数名和参数。冲突快照、损坏参数、混合协议、服务端错误不会被猜测成成功。
3. **放行模式遗漏分支**：原普通编辑已有自动应用，但“按计划执行”没有；只有记忆/技能变化时也被“必须存在剧本差异”条件挡住。现普通编辑、计划执行、分解执行、三堂会审统一处理：完成且校验通过即提交，保留结果总结、历史和撤销功能。

放行不等于把错误数据强制落盘：中途停止、未完成、需澄清、校验不通过、案卷已切换、并行编辑冲突、编辑器未确认提交，都不会自动应用。共审仍需审批，问策仍先只读规划。真正缺少需求信息时仍允许国师提问。

## 恢复边界

- 一次逻辑调用中的原生/文本协议协商共用一次格式恢复额度，不因切换协议重新获额度。
- HTTP 重试计数不因格式恢复重置：原 HTTP 重试默认最多三次，额外最多一次格式恢复，不形成多层相乘。既有工具协议协商仍有各自一次性条件；跨协商的真实请求次数统一统计，格式恢复额度不再获得第二份。
- 损坏响应中的所有工具均不执行；之前完整轮次的草稿和配对工具历史保留。恢复只重取失败的这一轮，不重做已执行的追加操作。
- 停止会取消读取和退避，不再发送后续请求。自动恢复会显示进度；次数、HTTP 请求量正确计入指标，损坏响应可能计费时标记用量不完整。
- 错误/诊断不带响应正文、思考内容、工具参数或 API 密钥。结束标记缺失且无可靠完成证据时，不凭“参数看起来完整”假造成功。

标准 SSE 用空行分隔事件，多行 `data:` 属于一个事件；本次逐行兼容是严格限定的非标准中转适配，不改写标准规则。[WHATWG SSE](https://html.spec.whatwg.org/multipage/server-sent-events.html#parsing-an-event-stream)。Anthropic 的块结束与消息结束有各自事件；缺消息结束时仍要求完整重取，不把工具块完成当消息完成。[Anthropic 流式协议](https://platform.claude.com/docs/en/build-with-claude/streaming)。
