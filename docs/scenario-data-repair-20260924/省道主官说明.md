## 字段与范围

- 只写 `level: province` 的行政节点。天启以 registry 的 `sourceAdminId` 定位；绍宋/晚唐的 registry key 可经节点 `id`、`mapRegionId`、`regionId` 关联。节点 ID、地图和首府引用保持原值。
- `governorOffice` 是官制职位引用：晚唐为稳定职位 id，天启和绍宋为唯一的 `部门/职位` 路径。`holder` 是唯一人物真源；节点 `governor`、`officialPosition` 仅同步显示，不加 `governorCharId`。
- 空席：保留可解析职位与官称，职位 `holder` 和节点 `governor` 都为空字符串。**出缺表示本轮未能落实姓名，不等于断言史实当时无人任职。**
- 无单一主官：`governorOffice: null`，`governanceNote` 只用 `分镇 / 土官袭替 / 羁縻 / 诸部` 四枚举，解释另存 `governanceDetail`。
- 玩家官制副本：天启只有顶层一份；绍宋顶层、宋廷势力两份，西军独立官制中的六路帅职另行同步；晚唐顶层、唐廷势力、registry 三份。晚唐 NPC 为势力、registry 两份；天启 NPC 没有原树者建立所属势力官制。运行时使用 `GM.officeTree`。
- 天启覆盖43个登记节点（玩家18、NPC25）；四家无领土地块的节点不扩展。绍宋本轮覆盖玩家28个节点，外藩76个节点维持原值，仅修一处继承人的官称前缀歧义。晚唐覆盖107个登记节点（唐廷45、河朔昭义四镇、外藩58）。

## 考证规则与校正

史料优先于原名册。H 表示已核原文所述事项；M 包括制度补全、邻月现任回证、转引及年龄推算；L 为弱证、未知值建模或沿前轮设置。**引文本身为 H 不代表把其记载的前后月份直接变成开局任命。** 各路的推定范围和未详项单列。

天启：顺天由刘诏改为单明诩，应天由毛一鹭改为李待问，浙江由潘汝桢改为张延登，广西由毛堪改为王尊德，江西由谢元珧改为杨邦宪，湖广由钱希言改为姚宗文，云南由闵洪学改为谢存仁，广东由李待问改为李逢节。贵州王瑊已迁南京户部，撤巡抚后由张鹤鸣总督兼黔务。刘诏、毛一鹭、潘汝桢保留人物并改为当时现职；熊文灿和马士英不再提前挂福建、浙江巡抚。

绍宋：京畿宗泽仍为东京留守；其余以安抚/经略安抚职为主。京西北孙昭远正文实授制置使，安抚是按帅府制度补全的职名，非发现一条另授安抚使的制书。河北战区沿用已有人物张所的河北招抚使；三泉是直隶县，空席为知三泉县。两浙、河东保留分镇。财官不补；原16席聚合帅司从两份官制树移除，逐路新增的职位沿原帅司俸额，不重复保留虚席。

晚唐以连接为主：河中郑肃从既有官位落到节点；华州职位改显示“镇国军防御使”而保留职位 id。金商、夏绥银宥继续出缺。韦长、李绅、李款等现职官称与对应职位对齐。外藩既有君长有据者新建职位引用，不新造人物。

消除全树官称前缀歧义：叶尔羌王子、郑柞、阮福澜、大延广及绍宋既有虚构少年脱黑脱阿调整称谓词序；赵哲从误提前的环庆经略改回通问副使。修改在数据模块的 `characterUpdates` 中逐条列出。
