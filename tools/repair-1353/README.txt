天命 1.3.5.3 根因修复器

先完全退出天命，再双击 launch.bat。修复器会优先修复当前活动的 1.3.5.3 热更新；没有热更新时，会扫描全量安装的 app.asar，并校验 package.json 版本与五个原始文件 SHA-256 后再原子替换。自定义安装位置可运行 `launch.bat -AppAsarPath "E:\版本\测试版1.3.5.3\win-unpacked\resources\app.asar"`。

若要撤销最近一次修复，在同一目录运行：launch.bat -Rollback
