# 晚唐·开成五年修复方案（阶段三）

同志 09-24 定：死字段删去（有用内容并进正规字段），引擎在读的新账本留作「可选扩展」写进宪法；砍批量「地方代表」，其余虚构人物逐个看有戏才留，补史实人物；立绘先复用晚唐现有的，缺的调 Codex 生成。09-25 同志又说：晚唐是三部里最糟的，不合理处与新字段很多，新字段或有好的，但所见以坏的为主。

## 一、现状要点（体检与 09-25 摸底）

- 体量：原账 60.7M 字符。同一批府州数据存了七份——`adminHierarchy`，地图里每个地块的顶层与 `data` 各一份，`map.adminHierarchy` 又整份拷贝一次，再乘 `mapData` 两份。
- 字段：`lint-scenario-data` 报 71942 处，其中死字段 70423 处（193 个字段名），格式问题 1261 处（人口写成对象、地形写英文、省道登记没有 `memberRegionIds`）。
- 另有约 600 个只有晚唐写、引擎在读的字段名，分属 Codex 新接的几套账：户口账、财政账、公帑、人物家产、人力、阶层处境、环境、军饷。
- 数字：207 处同一道下三个以上府州人口相同（按系数平分），如陕虢二州各 33264 户、河阳两州 38017/38016 户。唐廷在籍户合计 431 万、河朔昭义 82 万，与《旧唐书·文宗纪》开成四年户 4,996,752 相当；境内实有口数 4180 万为作者估计。
- 长官：44 个道只 9 道有长官（连河朔、昭义四镇共 13 人），府州一律无 `officialPosition`、`governor`；十余个道的名目写「上级地理/行政分组」。
- 外藩：区划名写成「图幅西缘接触地」「辽东归属待核带」「吕宋北部窗口」一类制作用语。
- 人物：434 人中 353 人虚构。其中地方代表按姓批量起名，挂在府州的 `localRepresentatives` 上，如文室广成挂 73 处、范元简挂 21 处。神策左军由虚构的陆文远统领，右神策军没有统兵官，清海镇张保皋不在人物表。

## 二、第一刀：字段清理与格式归一（`patches/tang-fields.js`，报告 `reports/tang-fields.md`）

- 先把后几刀要用的原账信息存到 `sources/tang-original-leaves.json`：县名表、原户口、原财政估额、道原官称与长官。
- 死字段按 lint 同一口径删去：139 个字段名、37835 处。另删地图里运行时不读的整份行政树拷贝。真源从 60.7M 字符减到 51.5M，preview bundle 从 101.5M 字节减到 94.5M。删去的主要是这几类：
  - 制作元数据：`metadata`、`scenarioCompatibility` 里的版本说明、`mapPackage`、`portraitLibrary`、几何溯源、边界可信度。
  - 重复信息：府州上重复写的道官称与道长官、人物的 `historicalFacts`（与简介逐字相同）、`abilityAssessment`（已在简介或处境里）、`relationshipHooks`（188 条均已在关系表）。
  - 按道套写的旁白：`fiscalNarrative`、`playRole`，后者里有「此地块可点击……并非圆形湖泊」这类制作用语。
  - 批量地方代表的挂名 `localRepresentatives`：人物本身留待人物一刀处理。
- ★口径修正：税目表 `taxList[].base` 用字符串按名字引用府州 `economyBase` 的海盐、池盐、井盐、茶、酒、商税、舶货、坑冶课额，以及另一势力的 `saltOutput`。代码里不出现这些字段名，按字段名判断会误删，导致盐铁税收不上来（`smoke-tang840-fiscal-detail` 当场报出）。
  - lint 与补丁都改为：字段名若在剧本数据里以字符串值出现，也算活字段。
  - 按这个口径，天启、绍宋也各少报几十处误判的死字段。
- 格式：
  - 575 个府州的 `population` 改为口数，明细原本就在 `populationDetail`。
  - 地形按地图图例改为中文（湿地按水乡计）。地块自身的 `terrain` 仍是图例键，不动。
  - 111 组省道登记改为 `memberRegionIds`。
- 道长官：
  - 47 道写上 `officialPosition`。原账已有长官的 12 道，官称与本人官衔一致，游戏可按官衔活绑定。
  - 其余道按唐制名号写。河阳三城此时名号有沿革问题，待第三刀核定。
- 验证：
  - 重建逐字节可复现；晚唐相关 smoke 全部通过。
  - 财政探针（VM 开局强征一年）清理前后逐项相同。开局一年唐廷中央入钱 1204 万贯，与大中年间岁入九百余万缗同一量级。

## 三、第二刀：户口重建（`patches/tang-households.js`，报告 `reports/tang-households.md`）

- 范围：唐廷 44 道与河朔、昭义四镇。各道合计一概不动（作者对开成年间的估计，在籍户合计与开成四年户籍相当），只改道内各州的分配。
- 权重：
  - 道内按《新唐书·地理志》天宝户（`sources/xintangshu-dili-37-43.json`）。
  - 天宝以后才设的州（宿、池、信、昌、澶、涿、孟即河阳三城、磁）：先看《元和郡县图志》（`sources/yuanhe-zhi.json`）有无开元户；没有就按所领县数乘本道每县平均户估。
  - 志与县名都没有的（天德军、南部羁縻、两个侨置州），保持原份额。
  - 新唐书用州的终名，对照写在补丁里：唐州作泌州、随州作隋州、交州作安南中都护府、磁州作惠州。仪州在开成年间仍名辽州，中和三年才改仪州，名目放在第三刀改。
- 为什么不用元和户：元和户离开成最近，本想拿来做权重。但各州括户程度悬殊，传抄又多讹：
  - 申州 614、象州 233 显系脱字；隰州元和户多于开元户，晋州却只剩一成。
  - 河朔三镇根本不上户籍，魏州只记 6920 户。
  - 所以只在报告里列作参考。安史乱后的区域消长，已由作者定的各道合计体现。
- 随人口重分的量：户口账各项、田亩、商贸额、府库开局存量、城市人口、地方水利驿路仓储开支与吏员，河朔四镇的销盐课也在内。
  - 做法：各州原账数乘本州人口变动倍数，再按道合计归一。
  - 所以道与全国合计不变；各州原有的在籍率、垦田率差别保留，原为零的仍为零。
- 不动的量：盐、茶、酒、商税、舶货、坑冶课额，连同酒坊工本。这些是按州定的旧额，不随人口走。
  - 起初把酒课也随人口分，`smoke-tang840-fiscal-detail` 的酒课校准（实收扣酿本后 104 万贯）当即报出，据此改正。
- 开局账：核对过，原账各州 `fiscalDetail` 正是财政引擎 `previewBudget` 按年预算的结果，所以重分后用引擎重算。
  - 开局一年唐廷中央入钱 1204.1 → 1202.3 万贯、粮 376.6 → 375.1 万石，差异来自各州征收率不同。
- 结果：
  - 唐廷与四镇的平分痕迹全部消去（晚唐 lint 平分 207 → 124，剩下的都在外藩）。
  - 例：河中府 87578 → 40586 户，天宝蒲州 70800、绛州 82204，原账把河中府写得过大；慈、隰二州不再相同。
  - 解析中发现「戶萬五百一十」开头省「一」的数被算成零，已修；宋、金史料没有这种写法，绍宋不受影响。

宪法第五节已把户口账、财政账、公帑、人力、阶层处境、边警列为可选扩展。它们留不留，看数值是否合理，逐套核：

| 账 | 初判 | 待核 |
| --- | --- | --- |
| 户口账（在籍/应税/隐户/逃丁） | 在籍户总数与开成四年户籍相当，口径可用 | 各州分配已随第二刀重算 |
| 财政账（12 个税目，各有史据说明） | 开局一年中央收入量级合理；两池盐岁课一百万贯合《新唐书·食货志》 | 各州课额是按系数摊的旧额，盐、茶、酒、舶货的产地分布须与史料对（第三刀） |
| 公帑与官俸、军饷 | 结构完整，smoke 有 1361 条断言 | 俸额、军额与史料对照 |
| 人物家产（田宅、店铺、债务） | 434 人都有，虚构人物同样有 | 随人物一刀清理；史实人物的家产量级抽查 |
