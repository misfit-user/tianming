天命 1.3.5.3 根因修复器

先完全退出天命，再双击 launch.bat。修复器会优先修复当前活动的 1.3.5.3 热更新；没有热更新时，会扫描全量安装的 app.asar，并校验 package.json 版本与清单内各原始文件 SHA-256 后再原子替换。自定义安装位置可运行 `launch.bat -AppAsarPath "E:\版本\测试版1.3.5.3\win-unpacked\resources\app.asar"`。

若要撤销最近一次修复，在同一目录运行：launch.bat -Rollback

本包包含地图写回生命周期、行政层级往返、国师大文件附件管线、校验器稳定问题键和非玩家行政包装人口语义修复。旧自建存档补上已证实的 GM.map 运行地图来源遗漏，避免被 P.map 模板地图替换；不会删除或重编号地块。由于尚无玩家真实失败档，仍请保留失败档和完整错误文本，以核对是否还有其他读档路径。

v2（2026-10-14）在 v1 基础上追加（用过 v1 的直接再跑一次即可，修复器认得 v1 写过的文件）：
