# 晚唐新补人物立绘清单（32 张）

第四刀之二新补的 32 位开局在任长官原先只有通用立绘。下表是给生图模型的描述：年龄、官职、任所与文武之分按 data/tang-people-new.js 的人物条目写，服色按紫三品以上、绯四五品大致取；面貌与神情史无记载，只求彼此有别，不当史实。

统一画风（与游戏里已有的晚唐人物立绘一致）：
- 写实油画质感的人物半身像，竖幅 3:4（约 1086×1448），人物居中略偏一侧站立，取景到大腿。
- 唐代开成年间（公元 840 年）的官员装束：圆领袍、黑色软脚幞头、革带（文官佩鱼袋），武将可着明光铠或在圆领袍外束甲、佩横刀。
- 服色按品秩：紫袍为三品以上，深绯袍为四五品。
- 背景是其任所的城景、山水或官署，暖色自然光，景深自然。
- 画面里不要任何文字、印章、边框、水印；不要画唐以后才有的建筑（如宋代的料敌塔、明清的城楼式样）。
- 每人面貌要有区别（脸型、胡须、神情、体态各不相同）。
