## 实际使用

1. 支持 `nativeStart` 契约的剧本，点击正式开局后直接选择势力／人物、模式和难度；没有 API 密钥也能使用已有的本地内容开局。未配置的势力显示原因，不生成替身元首。
2. 在现有剧本编辑器顶部点击 **“工”**。先保存案卷，再导入中立底图 ZIP／JSON、资料附件。导入只创建当前案卷资产，不自动改变剧本归属，也不覆盖原文件。
3. 继续使用原有国师聊天。可要求检查地图、提出修改、应用到草稿、编译指定身份、运行原生沙盒、生成并验证制品。`mapAssetId` 可省略；显式填写时用当前绑定的资产 ID，不是地图名称／地图 ID。
4. **共审**：整包审阅后批准。**放行**：任务完成且质量检查通过后，直接通过同一事务入口入库并总结；未完成或校验失败的草稿不会自动应用，界面说明原因。
5. 制作任务可以设定请求数和允许修改的地块 ID。0 次表示仅本地处理；只授权局部地块时，全局字段工具不能绕过范围。共边修改须同时授权双方。
6. 持久任务在工作台中明确“恢复”后取得新租约。保存已完成草稿、工具对话和回执；预算耗尽不扩额。人工编辑造成版本冲突时保留候选，需重基／另建任务；取消后的旧候选不能迟到提交。
7. 制品列表选择 **导出**。桌面另存采用受限原生对话框、独占落位及 SHA 回读，拒绝同名覆盖；旧桌面壳不具备新接口时回退可用浏览器下载路径，显示“已交给浏览器下载”，不冒称写盘成功。

- 单份不可变世界源、稳定人物/势力 ID、元首／摄政／受托代表、授权与规则能力检查；选择摘要不反复克隆世界，确认后仅生成一个候选。
- 真实隔离初始化、取消／过期请求拦截、现有 `fullLoadGame` 回滚和双槽 canonical 存档事务。继承保存初始与当前人物身份，不重置国庫。
- 世界社会注册表与本方视图并存；保留外国人物、党派、阶层、官署、部队和事件。财政使用明确账户、责任方、代付份额与实际在任者；空职、零值和禁用私库不会回填皇产。
- 地图几何在固定 Worker 中处理：共享边、孔洞诊断、多面、拆并守恒、明确引用迁移、物理邻接。`mapRegionId`、`mappedRegions`、人物／部队／官署／事件目标联动更新，歧义阻止整包提交。
- 原 JSON、底图 JSON、编辑器投影、绑定 JSON、CSV、Markdown、ZIP、真实原生 PNG；文件字节、输入摘要、代码指纹、运行编号、缓存来源及许可随结果保留。
- 原中立底图 ZIP 的原件和 5 份许可文本逐字节保留，包括 BOM。地理数据许可不被改写成工具的 MIT 许可。
- 新增导出主进程模块已登记安装包资源；没有暴露 `fs`、`exec` 或关闭 sandbox／CSP。

## 明确的能力边界

- 原生财政流量支持显式 `none`／`fixed`／`region-tax` 与既有三资源账册、费用和分账。地块税收必须声明 `taxBase`、`taxBaseResource`、`taxBaseUnit`、`taxAuthorityFactionId`；税权方公共账户声明 `flowModel: {type:'region-tax', periodDays:30, rate:0.1, expense:0}`。税权可与主权、实控不同；改地图颜色不转移税权。显式 `null` 税权暂停征收，单位不一致/缺账户/未知规则拒绝，不能偷用默认税制。
- `runSandbox` 是真实初始化以及最多 3 期确定性财政／事件消费者，**不是付费 AI 完整推演回合**。PNG 来自同一快照的正式地图渲染器，不是生图。
- 无外部搜索服务时，来源工具只读取已导入的本项目资料。PDF／图片可保留原件并标“待提取”；没有提取器就不伪造页文。不存在任意 URL 抓取／任意代码执行接口。
- 本轮实际平台是 Windows + 锁定 Electron 33.4.11。未进行安卓／移动实机验收，不宣传已验证移动端高级工作台；基本能力缺失时给明确失败和替代路径。
- 原独立中立图 575 个地块、622 个面片、228 个内环已完整运行；政治归属使用合成夹具，不是新建或修订晚唐剧本。

大图校验曾触发开局编译的 30 秒限制。已对共边检查加入每次计算独立的边段空间索引，并复用孔洞/地块边界框；没有删点、抽样、跨请求信任旧缓存或放宽容差。完整原图的前后校验报告逐字节相同（94,039 顶点、1,478 条邻接），证据见 `geometry-index-verification.json`。该记录是单次本机 Node 对照，不是游戏 FPS 保证；缩放渲染路径尚未改动。
