# 国师直接操作地图编辑器

## 使用

重新打开地图编辑器，点击右下角 **国师**。沿用游戏／剧本工坊的模型配置，无须启动额外服务。

可以直接输入：

- 使用天启剧本的三级地图，把顺天府改名为燕京。
- 使用绍宋剧本的三级地图，把开封府改名为汴京。
- 只使用绍宋剧本的府州地图。
- 只使用天启剧本的省道地图，然后修改指定省道的名称。
- 把选中的地块归属改为地图中已有的势力。

载入与后续修改在同一条指令中完成，成功后显示在画布。**撤销上次修改**撤销整条指令；已有后续手动修改时，使用编辑器原有历史记录。**仅查看**模式不提供写工具。**停止**会取消本轮，不应用未完成结果。

三级地图的顶部新增层级选择器，切换 **天下／省道／府州**；绘制与点击选中都跟随当前层级。导出使用原有 **导出** 按钮。原生 JSON 会保留全部层级、来源和名称。从剧本工坊打开的地图仍可使用 **返回剧本（写回地图）**。

## 已接入的剧本

目录来自仓根官方 JSON，当前包含三套地图：

| 剧本 | 天下 | 省道 | 府州 |
| --- | ---: | ---: | ---: |
| 天启七年·九月 | 19 | 43 | 307 |
| 绍宋·建炎元年八月 | 35 | 104 | 566 |
| 晚唐·开成五年 | 42 | 107 | 575 |

三级的含义是 **天下 → 省道 → 府州**。省道按真实的 circuitRegistry 成员合并轮廓，再按实际归属分组；天下按势力合并。绍宋的 101 个原始省道／地域分组在按归属拆分后形成 104 个省道地块。单层提取生成该层的独立副本，保留来源 ID。

多部件轮廓、飞地和孔洞保留；名称后缀不决定层级。修改副本不会覆盖官方剧本。三级地图的归属或底层边界经国师修改后，会重新计算上层轮廓。上层独立改边界时，可先载入相应单层副本。

## 工具与执行

复用现有 TM.AuthoringAgent.runAuthoringLoop、provider、取消信号和回执。地图操作指引随每轮注入，先支持内置国师。

| 工具 | 能力 |
| --- | --- |
| listScenarioMaps | 按名称检索剧本地图、真实层级、数量及来源 |
| loadScenarioMap | 按稳定剧本 ID 载入完整三级或单层副本 |
| mapEditorOverview | 分页检索地图、层级、选中地块和现有势力 |
| mapEditorRead | 按稳定 ID 读取属性、分页读取边界顶点 |
| mapEditorFocus | 在画布定位地块并切换到相应层级 |
| mapEditorEdit | 批量修改名称、归属、地形、说明及已支持属性 |
| mapEditorMoveVertex | 调整边界顶点，联动共享坐标／拓扑顶点 |

工具先修改隔离候选。整轮成功后，经 commitMutation 一次写入并回读；写入不一致会恢复原图及历史记录。模型返回期间若发生手动修改、撤销或换图，旧结果不能覆盖当前地图。成功后的追问保留会话，手动编辑或换图会清除旧工具上下文。

地图国师已取消固定的 24 轮限制和整轮 token 预算上限。工具回执以完整 JSON 送回模型，不再按 1200 字符截断，也没有另设 64K 回执截断。分页仍可继续读取后续数据。模型／接口的实际上下文容量、取消、失败和无进展处理仍由现有执行器处理。

返回游戏格式时，完整三级只输出底层地块与真实省道分组，避免把上层聚合轮廓重复计入地块。当前工具尚不支持新建势力、绘制新地块、分割／合并或编辑道路河流；地图操作不自动修改剧本行政账。边界检查覆盖零面积、自相交、孔洞越界，单环支持最多 2000 顶点。

## 地图库生成与校验

真源为 scenarios/*（官方）.json。地图资产生成到 web/data/maps/scenario-library/，不包含人物或其他完整剧本内容。来源路径为相对路径，目录记录源文件、资产和生成器的摘要。

官方剧本更新后执行：

```powershell
node scripts/build-map-editor-scenario-library.cjs --write
node scripts/build-map-editor-scenario-library.cjs --check
```

新增的地图回归检查会校验当前真源、生成器和资产是否一致。浏览器从本地目录按 ID 加载并校验字节数与 SHA-256；Electron 的 file:// 与网页 HTTP 读取均已验证。
