# 天命 1.3.5.2 · 山河境正式接入

本版发布网页与源码，不制作 EXE/APK，不发布桌面热更或安卓 Capgo 更新。已有安装包不会自动获得本次网页更新。

## 山河境 2.5D

正式地图默认接入已验收的 B5/R2「清晰度 C1」，在原有天下、省道、府州地图与操作之下绘制山川、城郭、田畴和林木。底图不内置地名或势力文字，不重做已有交互，也不改写剧本地理和账目。

地名与势力名使用同帧投影，保留原生势力配色、金色选区描边、悬停和方志入口。清晰度处理包括连续地表细纹、颜色纹理分级采样、自适应岸线与政区纹理、高像素密度画布。WebGL2 不可用或地图缺少受支持的配准信息时保留原地图。

三份官方地图读取当前剧本：晚唐575块、绍宋566块、明末307块。B6 水墨审核稿不在本版发布范围。高度仍为美术高度场，不是实测高程，也不进入行军、人口或推演计算。

## 同步整合

人物图志与问对：操作只绑定当前在册人物，不再把展示用的人物副本误判为同名冲突；同ID更新正确接续，读档、换局、同名替换和旧确认窗口不能误召见其他人物。

本地同期内容还包含敕令长期执行、税政账目、实时局势和个人记忆接续、党派与阶层形成、官署创建，以及主副接口重试次数控制。发布整合保持各自账目写入口；补齐新阶层定性裁定的迁移接线，并拒绝跨存档、回滚或手动修改后的旧裁定回包。


记忆系统补充长期档案、来源边界、模型能力证据与混合检索。推演和存档完善完整性校验、失败恢复、快照与分卷回执，避免未确认结果被标记为成功。

主副接口分别设置等待策略，区分排队、首响应与完整正文，保留玩家设置的等待上限和取消行为。舆图补齐明末府州几何、合并账目显示和易主刷新；地图编辑器及战场减少静止时的重复绘制。

内部 npm 版本使用1.3.502，内容版本使用1.3.5.2。本版不制作安装包，不更改已经发布的客户端更新通道。

素材来源与许可见 web/vendor/shanhe25d/NOTICE.md。工程测试不代表所有真实供应商、移动设备和长期游玩均已验证，不承诺固定帧率。
