## 已实现

**打开数据库不会无限等待。** 默认打开期限 15 秒；阻塞、打开异常和超时会释放本次连接缓存。已失效请求的迟到成功连接会关闭，迟到升级会尝试中止，旧请求的错误或关闭事件不得清空后来建立的新连接。

**事务操作有明确期限。** 默认每项数据库读写操作为 30 秒。超时尝试 abort，清理对应缓存连接，保存有界诊断。若无法确认事务结果，记录 unconfirmed，不凭超时推断“肯定没写入”。以上是异步阶段期限，不是整个回合的总时限；浏览器事件循环阻塞或系统挂起时，定时器也可能延迟。

**正常结果不删减。** 正常写入仍等待真正的事务完成，完整世界正文和快照内容原样保存；旧快照上限仍为 200，数据库版本仍为 6。清理超时不会删掉成功写入的快照，也不会把尚未成功的删除报告为成功。后续正常清理可以重新执行。

**安全边界保留。** 主存档已经提交时，附加快照超时走已有的警告路径，不回滚已保存的完整回合。时间回溯所需的返航点属于必要前提，写入超时仍阻止进入目标回合。异步期间切档后，不向新世界发布旧保存标记。

**诊断与资源清理。** 新增 `StateSnapshot.diagnostics()`，最多保留 12 条阶段、错误码和中止状态，不含人物、正文、完整存档或密钥；正常成功与失败均清理定时器。诊断仅保存在本次页面会话中。
