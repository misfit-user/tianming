# 晚唐 v19 校订说明

本轮在既有正式晚唐剧本上修订，保留488人、575地块及126张立绘。深化35名人物，给488人补充地方行政关联，核查47势力的政治范围和财政制度。地方关联中的参考地点不等于人物实际所在。

## 人口口径：按用户纠正处理

古代史料户口不能直接当作实际人口；在籍、隐户、逃户、实际人口估计与可征税基分别处理。日本原模型433,399口保留，不能因此称它为已证实的840年在籍数。日本800年约550.62万人估计仅作参考，没有写入户口、田亩、税基或库存。[日本人口问题研究所](https://www.ipss.go.jp/syoushika/tohkei/Data/Popular2007/T01-06.html)

开成四年4,996,752户为史料所报户数，既非口数，也不能直接套用为玩家地图范围。[唐会要卷84](https://zh.wikisource.org/wiki/唐會要/卷084)

逃隐比例是显式的作者情景参数，并非按实际人口减登记数倒推。现有引擎将隐户和逃户作为同一人口总量内的户籍状态，旧字段registeredMouths命名与这种分区语义并不完全一致；本轮没有宣称完成全引擎人口字段或界面重构。登记隐口改变状态及有效税基，不凭空增加人口。开局已启用既有户籍桥接；NPC财政通过自选开关调用原有逃隐折损公式，其他剧本未启用时保持原行为。

## 行政与地块

日本73节点整理为畿内及七道；武藏归东海道，加贺独立，不把边地城栅拆成虚构国。吐蕃38节点整理成五个明确标注的地理管理组，不冒充历史行政省。95处叶级地区补充上级行政长官关联，不视为兼任各州刺史。十处交通节点按情景补充驿路状况；驿站数量不是史载统计。

575地块几何、中心及邻接保持不变。修复行政登记表重复／幽灵成员、河中等人口镜像过期问题；人口初值、城市镜像、地图与行政副本统一。玩家地图模型合计18,845,715口、3,769,138户；这不是史载全国实有人口。详细字段变化见reports/changes.json及demographic-accounting.json。

### 各势力结论

- **唐朝廷**：皇帝、中枢与方镇共同构成唐的政治体系；图中另列四镇是财军控制分账，不代表840年四个外国。两税、盐利和江淮转输并用，户部、度支、盐铁职责交叠；中央库存不能等同天下总财富。 证据等级：institutional-context-only；来源编号：NT52、NT53、ZZ246。
- **唐·魏博镇**：何进滔仍在镇；何重霸承镇与赐名是后续事件。军中拥戴、朝命与实际控制须分开。军府掌握本镇征收及军用；不把中央地方平均分成自动套用到河朔。 证据等级：institutional-context-only；来源编号：ZZ246、NT64。
- **唐·成德镇**：王元逵在位，镇冀深赵四州按军政辖区表达；对唐名分与地方军权并存。本镇收入优先支军府；对朝贡助须有具体交付，不能视为中央日常直征。 证据等级：institutional-context-only；来源编号：NT64、ZZ246。
- **唐·卢龙镇**：史元忠为开局镇帅；史书的后来军变不能使张仲武提前占据幽州。幽州边军兼有地方征收、互市与边备压力；实贡不等于均匀上供。 证据等级：institutional-context-only；来源编号：NT64、ZZ246。
- **唐·昭义镇**：刘从谏在位，太行两侧五州构成军政整体；刘稹继承争议尚未发生。潞泽与山东邢洺磁的转输条件不同；后来的讨伐耗费不倒灌年初。 证据等级：institutional-context-only；来源编号：NT64、ZZ246。
- **吐蕃**：赞普王权仍在，宫廷、军政贵族和各地驻军控制有差异；后来的大分裂不得提前写成既成事实。农牧征调、实物供给与地方军需并行；河西绿洲与高原牧区不可按相同货币化程度计收。 证据等级：institutional-context-only；来源编号：NT216b、ZZ246。
- **南诏**：劝丰祐王权以洱海区域为中心；赕、节度及受控制地方的层级不能直接写成唐州县。洱海农业、山地畜产与通往川蜀及骠地的运输并存；军需征集有地方和季节约束。 证据等级：institutional-context-only；来源编号：NT222a。
- **回鹘**：年初仍为阖馺可汗的牙帐体系，839年的内争与牲畜灾损已成压力；840年后续破牙未发生。马畜、织物及边口交换比统一田税更关键；牲畜灾损削弱可征物资，库存应表现真实脆弱性而非默认健全。 证据等级：institutional-context-only；来源编号：ZZ246、NT217b。
- **黠戛斯**：有可汗和部众组织，长期与回鹘冲突；840年内的胜利结果不预装到正月。畜牧、局部耕作和交换共同供给，现金税不能代表全部征调。 证据等级：institutional-context-only；来源编号：NT217b、ZZ246。
- **契丹诸部**：诸部及其联盟在唐与草原王权之间活动；不能提前使用907年以后辽朝国家机构。牧畜、狩猎和交换义务按部众落实，数值是聚合预算。 证据等级：institutional-context-only；来源编号：NT219。
- **奚诸部**：部落首领与邻近军镇、草原政治体交涉；地图色块不等于固定国界。畜产和交换供给为主，局部农业不意味着普遍编户田税。 证据等级：institutional-context-only；来源编号：NT219。
- **室韦诸部**：室韦是多支群体的总称，诸部生活环境及对外关系不同，不设单一皇都。渔猎、畜产、皮毛与零散耕作分区；公共预算只作各地可协商资源的合计。 证据等级：institutional-context-only；来源编号：NT219。
- **渤海**：大彝震为王；五京等制度见史籍，但本图八地块不是完整十五府六十二州的复制。耕作、贡赋、交通与朝贡交换并存；不能因称海东盛国而把每处边缘都设为富庶直辖区。 证据等级：institutional-context-only；来源编号：NT219。
- **新罗**：庆膺继位后王京贵族与清海势力仍有不同权力基础；九州、王京和清海军镇不应同列为十个独立国家。国王、贵族及地方征收并非同一账簿，谷物与织物给用较重要；海外贸易所得不能全算王京税入。 证据等级：institutional-context-only；来源编号：SK11、SK35、SK40。
- **日本**：仁明朝的五畿七道、国郡框架仍在；陆奥、出羽城栅辖区与北方地方社群须区别。国衙、郡乡、京库以及寺社贵族的收益权不同；钱、粮、帛是统一游戏资源而非照搬唐两税。 证据等级：institutional-context-only；来源编号：JP9、JP-POP。
- **海南诸峒**：岛内地方社群的观察集合，与沿海唐州的实际控制范围有别，不是全岛统一王国。地方交换、农业及山地生计；合计库存不赋予某一角色征用全岛财物的权利。 证据等级：unresolved-regional-model；来源编号：DESIGN。
- **台湾诸部**：不同河谷、海岸和山地社群的玩法集合；无证据建立840年统一国家或统一税制。地方生计与交换的公共筹措采用小额模型，不声称存在贯钱征税。 证据等级：unresolved-regional-model；来源编号：DESIGN。
- **占婆诸地**：沿海政治中心和地方统治者相互联系；环王、占婆称谓有时代及文献差异，不能把后世都城沿革直接前推。沿海交换、耕作与地方贡输并存，港口收益不应均摊给内陆每块。 证据等级：institutional-context-only；来源编号：NT222a、DESIGN。
- **骠诸城**：骠城传统在九世纪经历军事冲击；832掳掠不证明所有城与灌溉系统同时消失。城周灌溉与寺院、聚落交换相连，战乱影响可用收入；不把整个伊洛瓦底河谷当一个完整国库。 证据等级：institutional-context-only；来源编号：PYU-UNESCO。
- **下缅甸河谷诸聚落**：下游聚落的地理集合，不能提前建立后世勃固或统一孟人王国。河口交换与稻作模型；统一名称仅供检索，不证明同受一王征税。 证据等级：unresolved-regional-model；来源编号：DESIGN。
- **湄公河上游诸部**：多条河谷与山地社群的集合；不得将后来的兰纳等政权前置。农业、山地物产与跨谷交换分散，运输义务只能就地协商。 证据等级：unresolved-regional-model；来源编号：DESIGN。
