# 新前端·页面期施工图

承地基（plan.md）。页面期把老界面的功能逐一在新前端上做出来，做完整体切换。功能清单以老界面功能总账为准（勘察稿 report-screens.md，52 项）。

## 〇、头一条：身份是一等参数

同志 10-06 提醒：天命要走非皇帝视角（CK3 式、官本位，见 docs/guanben-roleplay-20260930/design.md 第九至十三章，09-30 拍板）。所以新前端不能把「皇帝」写死，**界面按「视角人物」的身份长出来**，皇帝只是其中一档。

内核眼下只能以皇帝身份玩（非皇帝玩法在设计稿的甲、时、乙、丙阶段）。页面期的做法是：

- **框架按身份做，皇帝档做全**，其余几档先立起结构；
- 用开发开关「借视角」（`?as=人名`）**以别人的眼睛看界面**，验证界面没有暗中写死皇帝。这个开关只换界面，内核照旧；借视角时案上动作一律只读。

### 0.1 视角人物（适配层 `perspective()`）

身份现算，不看头衔文字（设计稿 9.1）：

| 读什么 | 从哪取 |
|---|---|
| 是不是元首 | 玩家：`playerInfo.playerRole` 为君主/emperor，或 `leaderIsPlayer`；别人：是某势力的 `leader` |
| 在任官职 | `TM.OfficeHolderState.activeAssignments(GM, 人)`：衙门、职名、品级、辖区提示 |
| 辖区 | `GM.adminHierarchy` 里 `governorId`/`governor` 是此人的区划 |
| 家产、名望 | `resources.privateWealth`、`resources.publicPurse`、`resources.fame`；贤能 `xianneng` |
| 所在地 | `location` |

档（tier）：元首 `sovereign`；京官 `minister`；地方官 `provincial`；不在官 `gentry`。将军、宗室、商人等以后各成一档（设计稿戊阶段），先就近归档。

### 0.2 身份档（`ui/model/identity.js`，纯呈现，不碰内核）

每一档定这几样：

| 项 | 元首 | 京官 | 地方官 | 不在官 |
|---|---|---|---|---|
| 书房 | 御书房 | 部院直房 | 签押房 | 书斋 |
| 案名 | 御案 | 公案 | 公案 | 书案 |
| 自称 | 朕 | 本官（按职：本部堂、本院……） | 本府、本县…… | 自称名 |
| 印 | 玉玺 | 部印、关防 | 府县印 | 私印 |
| 令 | 撰写诏书 | 行文 | 行文：札付、牌票、告示 | 家令、公呈 |
| 批 | 百官奏疏 | 批详 | 批详、堂判 | 家事、乡事 |
| 书 | 鸿雁传书 | 私书 | 私书 | 书信 |
| 见 | 召对朝议 | 谒见、会推 | 谒见、接见 | 拜谒、文会 |
| 行 | 巡幸行止 | 行止 | 行止：巡视、告假 | 行止：应试、游学 |
| 顶栏账 | 帑廪、内帑、户口 | 公费、家产 | 辖区户口、公费、家产 | 家产 |
| 顶栏四品 | 吏治、民心、皇权、皇威 | 名望、贤能、康健、心绪 | 同左 | 同左 |
| 舆图 | 全境 | 全境，京师居中 | 辖区居中，描边 | 本籍居中 |
| 右列书目 | 舆、奏、人、官、财、军、史 | 舆、人、官、邸、谱 | 舆、人、官、册、邸、谱 | 舆、人、族、产、邸、谱 |

- 「诏付有司」那方印改为本档的「用印」（元首：诏付有司；官员：用印发文；不在官：封缄）。
- 推演键在时钟里（身份中立）。时钟已经留好调速与暂停的位置，等引擎的「时」阶段（即时加结算）接上。

### 0.3 守卫

`tools/newui/lint-ui-identity.cjs`：界面代码（screens、kit、scene、app）的字符串里，不许出现只属皇帝的字（朕、陛下、御案、诏书、奏疏、玉玺、臨朝……）。这些字只能写在身份档里。适配层不在此列，它转述内核原话。

### 0.4 书房

御书房已经有了。部院直房、签押房、书斋要新建（同一条 Blender 管线），排在页面期中段。建好之前，借视角先用御书房的骨架，换上本档的匾、联、案上器物，以示意为止。
