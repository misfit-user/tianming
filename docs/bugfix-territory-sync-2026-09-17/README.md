## 已复现的问题

地图易主入口只修改地图对象，未同步权威归属表、行政区划和国家领土；归属表入口则未同步地图。正式地图优先读归属表，因此新旧数据可能互相覆盖。

旧接口同归属调用仍重复追加历史；无主归属触发空对象异常。名称和 ID 别名可能残留，国家领地索引可能重复计数。兼容易主事件在写入后读取旧势力，产生错误的 from 字段。

实际回合提示词使用 P.map 和 P 的势力列表，而不是 GM 运行态；概览只展开前五个领土，且缺少邻接/资源数组时整个地图提示词可能报错。边境检查按地名去重，误合并同名地区的不同边界。
