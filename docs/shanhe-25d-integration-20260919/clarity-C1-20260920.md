## 实际变化

原代码已经使用线性采样和动态画布，本轮不是把所有纹理简单改为线性，也不是给全屏加模糊。

1. 地表硬方格噪点改为连续、按屏幕采样尺度衰减的细纹，抑制细密条纹缩小时的干扰。
2. 山体阴影和凹凸明暗统一使用取样高度，避免把粗三角网格的插值误差带进地表明暗。
3. 颜色材质采用近景三次重建、远景多级过滤和最多4倍各向异性过滤；不支持扩展时保留普通过滤。高度纹理不生成 mipmap，地表投影和点选高度采样保持原来算法。
4. 海岸、政区着色和选中层按实际画布与缓存范围分配像素，并设显存预算。标准档单层上限约838万像素、边长不超过4096；并非固定把所有层开到4096平方。
5. 标准档画布支持到 DPR 2，同时保留总像素预算。田块的相邻色差更协调，位置、数量、田埂与原有建筑模型未删除。
