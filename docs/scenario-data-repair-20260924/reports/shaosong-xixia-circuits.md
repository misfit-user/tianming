# 绍宋·大夏补路一级报告

大夏行政树去掉「大夏」国号节点（甘、肃、瓜三州原账各拆两笔核算项，并回一块），17 块分到 4 路下。全国合计守恒自检：口、户、丁、逃户、隐户、应征、实征、起运、留用、库钱、库粮、库帛、商贸、驿站、解额、地块数 全部与改前相等。

户数：西夏兵民合一（《宋史·夏国传》「率二丁取正军一人」），按卷四百八十五元昊时各地兵额分区，区内按《新唐书·地理志》天宝口数分州；势力全国合计不动。
