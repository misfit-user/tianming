# 晚唐势力标注与分级边界修复

当前交付按用户最新追加要求执行：三个层级都用对应疆域拟合纯文字（字号/朝向/横竖排），全层级下限约 3 屏幕像素，无框/引线/替代小点。天下按势力整体、省道按同一行政组的合并疆域、府州按自身地块。防重叠使用实际字形有向框。晚唐当前天下可见39名；省道111组中103个标签过LOD/碰撞、府州575个中482个过LOD/碰撞（含画面外标签）。早先名牌及5px中间版回执均保留追溯，不冒充最新版视觉结果。

## 根因与实现

晚唐 v21 的 575 个地图图形全部是府州级；旧代码在没有省道独立图形时退回全量，因此天下/省道都画出了府州边界。用户 C 本地也尚未同步上一轮 E 分支的疆域内接国名排版。

- 只读共边网格：天下取消同势力内界；省道按真实 `parentId`、`circuitName`、`circuitRegistry` 取消同省道内界；府州保留细界。不把叶节点 `provinceName` 误当独立省。
- 按边两侧填充归属判断共边，支持分段/T 结点，保留岛屿、湖泊、飞地和海岸。连续轮廓拼接减少独立 SVG 线帽。原始着色/点击路径不改，仅关闭重复描边和光晕；选中不会重新显露下级界。
- 所有势力统一使用疆域内深墨纯文字和浅描边，字号与朝向适配实际疆域。已撤下小势力名称牌方案：不生成底框、引线或替代小点。实际字形小于约 5 屏幕像素时隐藏名称（含键盘焦点），地块仍可点击/右键查看详情。窗口变化重新布局。
- 国名用有向矩形碰撞，修正长斜国名被轴对齐外框误隐藏。省道显示实际行政组名，旧地图仍保留 `title` 改名覆盖。
- 几何、归属、行政组变化使缓存失效；未变地图复用 SVG/轮廓。不改地理数据、不降低地图分辨率。
