天命 1.3.5.3 根因修复器

先完全退出天命，再双击 launch.bat。修复器会优先修复当前活动的 1.3.5.3 热更新；没有热更新时，会扫描全量安装的 app.asar，并校验 package.json 版本与清单内各原始文件 SHA-256 后再原子替换。自定义安装位置可运行 `launch.bat -AppAsarPath "E:\版本\测试版1.3.5.3\win-unpacked\resources\app.asar"`。

若要撤销最近一次修复，在同一目录运行：launch.bat -Rollback

本包包含地图写回生命周期、行政层级往返、国师大文件附件管线、校验器稳定问题键和非玩家行政包装人口语义修复。旧自建存档补上已证实的 GM.map 运行地图来源遗漏，避免被 P.map 模板地图替换；不会删除或重编号地块。由于尚无玩家真实失败档，仍请保留失败档和完整错误文本，以核对是否还有其他读档路径。

v2（2026-10-14）在 v1 基础上追加（用过 v1 的直接再跑一次即可，修复器认得 v1 写过的文件）：
1. 读档不再因「指向不存在的稳定 id」（如 地图地区[418].factionId → 台湾诸部）或人物/势力/军队/地区的重复 id 整档拒载：按名能找回的找回，找不回的清掉引用、保留显示名，并在存档的 _stableIdMigration 里留收据。

4. 过回合报错的提示里带上出错位置（函数@文件:行），完整堆栈保存在本机，「回合耗时诊断」面板可查看并一键复制；回报问题时把它连同存档一起发来即可。
5. 完整安装版：渲染层报错同步写进桌面日志（tianming-*.log）。热更新目录没有主进程文件，这一条要等下个完整安装包。

v2.3（2026-10-16）在 v2.2 基础上追加（用过 v1/v2/v2.1/v2.2 的直接再跑一次即可）：
1. 自建剧本「所在地和区划名称写得一致，第一回合却一个人都没有」：编辑器导出的人物不带 id，开局把 "undefined" 当成玩家身份收据存进了存档，之后按 id 找不到玩家、所在地退回「京城」，问对/廷议/常朝只认京城别名，自建地名全被当「远离京师」。现在开局先给玩家补稳定 id 再写收据；读档迁移会按唯一玩家标记或唯一同名把旧档的收据修好（读一次即修好、再读幂等）；两个玩家查找口在收据对不上任何人时也改为按名/按标记兜底，不再直接判空。
2. 自建剧本「设定回合入三百万，上期回合入却是 1.4 亿」：民心硬链接在非统一账本的剧本里把各州合规率写成了百分数（85），税收上解拿它直接当乘数，中央岁入、粮、布全部放大一百倍（真档复现：修前 1.66 亿/回合，修后约 293 万/回合）。现在合规率统一按 0..1 比例写，税收读侧把旧档里残留的百分数折回。已经被放大的国库余额不会自动回退，可用问天把国库改回去，或重新开局。
v2.4（2026-10-17）在 v2.3 基础上追加（用过 v1/v2/v2.1/v2.2/v2.3 的直接再跑一次即可）：
