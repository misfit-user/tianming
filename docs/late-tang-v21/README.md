## 实际消费与显示修复

- 奏疏、时政与来信通过真实开局入口载入；撤去重复的奏首、奏尾包装和可见的程序说明。
- 文事原文进入运行作品库，详情、传抄与保存读取同一份作品；不因默认未品而自动遗忘原作。旧档已有清空、删篇、查禁或改写不被重新播种覆盖。
- 人物关系的正负亲疏与五维观感分开换算，避免把旧交读成敌意；图志不再把职业文字一律当作官职。
- 改元与颁诏确认显示在御案前方；取消保留草稿。朝会询问复用同一层级，不把十日回合写成必然进入次月朔朝。
- 方志区分口与户，隐匿、逃散按人口估数显示。未有地方依据的年龄、性别、族群与信仰自动补值不作为地方统计呈现；地形代码转为可读称谓。

既有人口、钱粮、军数和地形几何保留。人口基数属于游戏的计量范围，不能直接等同实际人口；隐口不是隐户，实际人口未作无依据的倍数推算。日历采用现有游戏历法，未新增天文朔闰换算。
