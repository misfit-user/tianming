# 晚唐·官俸军饷报告

改单个职位 2 处、诸节度使 25 员按会昌三百贯、神策三营按边军两倍给、骑军四军补马料（钱/粮/布，每月）；职位三份一并改。后三项按史实会让开局财政吃紧（同志 09-27 定按史实算）。京官整组重定工作量大，列在末尾。

## 诸节度使

诸节度使现给钱 88.25、布 73.5，折料钱 176.5 贯，对会昌「節度使，三十萬」（会昌六年敕「料錢厨錢共三百貫文」）只有 0.59，加会府刺史本俸则为 0.46。按三百贯、半钱半帛改为钱 150、布 125。（可信度 H）依据：《新唐書》卷五十五·食貨五（會昌後百官俸錢）：「節度使，三十萬。都防禦使、副使，監軍，十五萬。觀察使，十萬。」；《冊府元龜》卷五百八·邦計部·俸祿四（會昌六年八月敕）：「夏州靈武振武節度使冝每月各給料錢厨錢共三百貫文」

改为钱/粮/布 150/10/125：河中节度使、河阳三城怀州节度使、河东节度使、振武节度使、朔方节度使、夏绥银宥节度使、鄜坊节度使、邠宁节度使、泾原节度使、凤翔节度使、义武军节度使、义昌军节度使、平卢淄青节度使、天平军节度使、宣武军节度使、义成军节度使、忠武军节度使、武宁军节度使、淮南节度使、荆南节度使、山南东道节度使、山南西道节度使、剑南西川节度使、剑南东川节度使、岭南节度使。
