## 实际修复

1. `web/phase8-formal-map.js`：地名查询只取需要的字段，不再反复复制大型附加账本；保持原字段覆盖、空值和归属优先级。权威归属命中后不再提前计算后备来源。名称和归属只在单次渲染内缓存，finally恢复；避免无变化图例、搜索框、缩放读数、模式与标签变换的重复写入。
2. `web/map-editor-culture-raster.js`：以精确三近邻空间索引替代每采样点遍历全部地块；保留采样间距、三邻混色、等距排序、透明度和输出尺寸。缓存签名包含实际位置和颜色，修复同数量修改、调色板变化、换地图时的旧图复用。
3. `web/map-editor-minimap.js`：保留原尺寸和地块画法；静态底图缓存，镜头变化只恢复底图并绘制视口框。空闲、隐藏和折叠状态不再绘制；修改、选择、换图、尺寸变化会失效重绘。公开render仍支持原地改几何。
4. `web/battle/index.html`：HUD、兵牌和命令栏仅在值变化时写入文字、HTML和样式，处理浏览器HTML/CSS标准化，保留零值、空值、外部DOM修复和冷却精度。三处只绘制的缓存Canvas不再一律请求软件画布，而跟随既有硬件/软件检测；软件回退保留。没有修改本轮的战斗结算、单位更新频率、分辨率、阴影或AI推演设置。

其他窗口并行修改的战斗标题页预热/遮挡循环逻辑已保留，没有覆盖，也不记成本轮独立修复。
