## 默认开启的可选玩法

| 设置 | 生效条件与保留的选择 |
|---|---|
| 军令移防 | 默认开启；玩家可以关闭，未设置时尊重剧本限制。仍检查军队归属、驻地、在途状态、道路和指挥权。 |
| 灾异模拟 | 默认开启；保留关闭。自然灾害并发上限 2、约三月冷却及确定性时序不变。 |
| 密探常侦 | 默认开启；保留关闭。必须存在符合条件的机构，仍受腐败、缺员和效力上限约束。 |
| 官制活化总闸 | 默认开启；移到普通设置可见位置。七项原有机制统一生效，关闭总闸后可逐项选择；出缺补员仍独立。 |
| 科场弊案 | 默认开启；保留关闭。按实际科举状态触发，不重复生成同一场考试的弊案。 |
| 奏报失真 | 严格史实模式默认开启；其他模式不生效，仍可关闭。失真显示不改真实账本。 |

官制总闸包括职权舆图、官员履职、权限门控、改制裁定、设衙章程、旧衙归树及官署按需细查。开启后改制进入原有裁定流程；旧衙迁移成功后停止旧预算扣支，避免重复收费。

## 审查中修复的问题

| 问题 | 修复与验证 |
|---|---|
| 弊案未读取当前腐败对象 | 读取 `trueIndex` 等当前字段；有效零值不被旧字段覆盖。 |
| 缺失奏报被显示为零 | 缺失、空值及非数值原样返回，不能伪造零。 |
| 负库存粉饰方向相反 | 按绝对值计算偏移，赤字粉饰为较小赤字；真实财政不变。 |
| 密报提前标记已送达 | 成功放入御案后才标记，御案未就绪时可以重试，成功后不重发。 |
| 官制总闸与子项未立即同步 | 切换总闸后立即重绘设置，子项恢复各自的勾选和可编辑状态。 |
| 原生数据的军队权限漏检 | 支持玩家势力 ID 与名称对应；拒绝指挥敌军，身份不明时不默认授权。 |
| 灾异地区仅识别旧数据 | 优先读取玩家行政区，其次读取所属地图区域，保留旧经济准灾信号及释放，不再因新地图结构而统一落到京畿。 |
