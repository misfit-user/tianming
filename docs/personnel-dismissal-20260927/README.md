# 革职显示成功但官制未变

## 根因

已用真实生成的 AI 写入器复现截图中的人事结果：`革职抄家·拘押候勘`。

旧写入器把“抄家”的“抄”写成了另一个 Unicode 字符，又漏掉了“革职”和“拘押”的完整识别。带有原官职时，这段处分被送进任命兜底；返回成功，实际人物却仍保留兵部尚书。没有原官职时，单独“革职”被静默跳过。史记照常显示 AI 的处分文字，于是与真实职位脱节。

## 修复

- 人事处分正确调用既有免职、拘押和抄家写入；“拟革职”“暂不革职”“留任察看”不会执行免职。
- 合法司法处分可读取普通回合本期颁行诏书及已登记的玩家命令；旧回合、草稿、撤回、在途命令不会新增授权。
- 免职沿既有官制入口按人物 ID 注销所有任职，清掉席位和旧身份字段，更新空额；嵌套官署的 `children` 分支也会处理。
- 人物图志继续读取真实官职字段；不另造与官制脱节的显示值。
