# 崇祯开局三级地图 R3：关宁、东江与漠南精修

## 使用

本地官方真源仍是 `scenarios/天启七年·九月（官方）.json`，开局日期、主角和名称不改。
重新启动本地项目，从该官方剧本新开一局。不要将旧存档强制换图。
地图上可切换天下、省道、府州；“全图”与“层级已锁”使用已有 R2 视图控制，不需要外部审图器。
本轮不是发版，没有提交、推送、打包或修改用户存档。

## 地图范围

在本机实际已有的 R2（296地块）上继续制作。R3有307个逻辑地块，43个省道编组。
关宁东江由1块变为8块：山海关、宁远城、锦州城、松山堡、杏山堡、塔山堡、觉华岛、皮岛。
察哈尔与漠南原6块细分为10块，只调整同一政权内部范围，合并后的原国界保持。
省道按府州实际并集生成；天下按当前势力聚合。不是三套互不对应的图片。

## 有限的历史控制校正

原锦州、松山参照点落在后金地块中。本轮按1627年宁锦防守关系校正一段狭窄关宁走廊；这不是完整复原辽东各城实控边界。
山海关周围同属明朝的少量原永平府几何，调整为军事控制单位。原有民政账目与数值不转抄改写。
觉华岛、皮岛取 Natural Earth 1:10m 物理陆地多边形。现代岸线仅作物理参照，不能称为1627年精确岸线。
皮岛多边形与原朝鲜粗岸线有极小重合，只扣除岛体交叠，不扩张到朝鲜大陆。
铁山、镇江堡、鸭绿江口的原账户仍分别保留在东江战区核算组中，不代表这些大陆地点在开局均为明朝稳控领土。
觉华岛原有人口、财政、驻军状态原样保留；新增真实岛形不代表1626年战损已经恢复。

## 数据保全

203条人物、48支原始部队、62条事件和382份原基层账户保留。
359份图内账户对应307个逻辑地块；23份原图外账户不为画图强行制造领土。
人物能力、描述、原驻地文字、军队兵額与将领、事件、阶层党派、官职、中央库帑和地方数量字段不重写。

## 适配与测试边界

所在地原文保留，增加稳定地块ID与地域候选。皮岛、宁远、锦州等不再共用一个辽东大块。
军队跨水连接明确标为 sea，不把皮岛、觉华岛做陆桥；出发与抵达仍由原游戏行军系统处理。
对启用精确地域优先的地图，地点解析先尊重完整地域名称，避免“镇江堡”被模糊当作江南镇江府。
另修正了府州方志读取上级总账的索引顺序：明确行政绑定优先；新细分地块不能用旧省ID兜底其人口、丁口和年龄构成。
原生财政函数的30日级联结算对比、单府转让、整省转让、收复及批次失败回滚都有独立测试。
JSON序列化检查不能等同真实用户存档迁移；隔离Electron测试不调用联网AI，不触碰用户实际存档。
完整长局、手机性能和正式发布验收不在本轮完成范围。全仓门禁结果见报告，不使用地图专项数量冒充全仓通过。

## 保留的地理限制

土默特、哈萨克各组、瓦剌、部分女真、科尔沁、喀尔喀及澳门共10个地域仍维持较粗粒度。
这些旧轮廓与城址、历史政权范围存在冲突，R3没有把参考点硬移入错误外框，也没有称它们已经精绘。
未涉及区域既有的跨省交叠仍被记录；本轮只保证没有新增未经登记的重叠和漏地。
府州内部界线是地理约束下的概化分区，不是历史测绘成果。
