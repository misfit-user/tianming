## 约见与赴约

1. 在同一面板选择联系人和 **文书表达** 或 **阅读理解**，选择可知会面地点。
2. 填写“开始于几日后”“停留天数”，选择**本人的**会后安排，然后点 **提出约见**。话题和来源随当前邀请记录；对方自行决定是否接受及自己的去留。
3. 正常推进日期，阅读实际收到的答复。看到 **按当前安排启程** 时，核对自己的安排后点击。
4. 途中继续正常过回合。未到场、尚未到约定时段或职责条件不符时，不能提前交流。缺少许可会显示具体职责和原因；不要重复创建同名邀请绕过。

会面不会把私人邀请变成官府命令。明确配置的多项职任逐项检查；未配置历史岗位仍有报告列明的兼容边界，不能据此推论完整假制已经实现。

## 到场与继续

1. 到达约定时段后，面板显示当前现场问题及本人可选操作。选择 **先问对方理解**、**解释要点** 或 **提出不同看法**。
2. 对方需要真实时间回应。玩家尚未作出的现场选择会阻止越过该选择；用完当天活动额度时，按剩余约定时段推进到下一日再处理。
3. 阅读“已听到对方现场发言”和“现场讨论结果”。完成一次交流、仍有分歧、未进行和提前结束是不同结果。
4. 继续日期推进，查看各自行程。**讨论完成不等于已经返回**；选择返回者沿路线返程，选择停留者保留实际位置。
